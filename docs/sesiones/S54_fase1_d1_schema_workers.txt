COMANDOS DE DESPLIEGUE (Wrangler)
----------------------------------

  # 1. Recuperar el database_id (solo si se perdió)
  npx wrangler d1 list

  # 2. Meter el database_id en wrangler.toml (pegando la UUID)
  sed -i 's|database_id = ""|database_id = "PEGA-AQUI-TU-UUID"|' wrangler.toml

  # 3. Verificar
  grep database_id wrangler.toml

  # 4. Desplegar
  npx wrangler deploy
