# EL BÚNKER — Taxonomía del VAULT
> Documento vivo. Modular: añadir/quitar categorías sin fricción.
> Objetivo: superar la convención de la industria de apps de pareja en un orden de magnitud.

---

## 📸 1. MULTIMEDIA
| # | Tipo | Descripción |
|---|---|---|
| 1.1 | Fotos | Selfies, screenshots, fotos de sitios, momentos cotidianos, polaroids escaneadas |
| 1.2 | Vídeos | Grabaciones, videollamadas guardadas, clips de momentos |
| 1.3 | Audio | Notas de voz, mensajes de audio, grabaciones ambientales (el sonido de un sitio), canciones dedicadas |
| 1.4 | GIFs / Memes | Con contexto: por qué lo guardaste, qué significaba en ese momento |
| 1.5 | Capturas de pantalla | Conversaciones cruzadas (WhatsApp, Telegram), tweets, posts |

## ✍️ 2. ESCRITURA ÍNTIMA

|---|---|---|

## Comparativa: Industria vs El Bunker

| Categoría | Apps de pareja típicas | El Bunker (objetivo) |
|---|---|---|
| Fotos | Álbum simple | Con narrativa, tags, geolocalización, vibe |
| Mensajería | Chat integrado | Cartas, drops, notas de voz, "abrir cuando" |
| Calendario | Fechas compartidas | Timeline emocional + hitos + cuenta atrás + flashbacks |
| Listas | TO-DOs básicos | Colecciones ricas con metadata, puntuaciones, enlaces |
| Documentos | ❌ No existe | Vault personal cifrado por separado |
| Crecimiento | ❌ No existe | Registro de conflictos, valores, terapia, check-ins |
| Mapas | ❌ No existe | Mapa emocional + viajes + wishlist geolocalizada |
| Finanzas | ❌ No existe | Presupuesto, ahorros, gastos compartidos |
| Legado | ❌ No existe | Contactos emergencia, voluntades, caja fuerte |
| Estadísticas | ❌ No existe | Resumen anual, rachas, mapa de calor |
| Rituales | ❌ No existe | Tradiciones propias documentadas |
| Multimedia | Solo fotos | Fotos + vídeos + audio + screenshots + GIFs + ambiente |
