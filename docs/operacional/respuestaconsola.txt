Lo que es Hermes según el código
Una HUD personal corriendo en tu PC (WSL2) con una interfaz React que actúa de panel de control central. El backend es un FastAPI de 1683 líneas — eso es bastante código, no es un esqueleto básico.

Cómo funcionan las piezas
La HUD (React)
Es tu cockpit. Tiene paneles separados para chat, terminal, editor de código (Monaco, el mismo motor que VSCode), agentes y contexto. Tiene tiendas de estado separadas para conversaciones, sesiones, servicios, errores... Es una interfaz bastante elaborada, no un chat simple.

El backend (hermes_api.py)
El orquestador. Decide qué va a Qwen local y qué va a Claude. Gestiona perfiles, sesiones, memoria, y emite eventos por WebSocket a la HUD en tiempo real.

Prometheus (el relay)
El flujo real según el código es:

Qwen detecta tarea de programación
  → busca plantilla en BIBLIA_DE_PROMPTS.md
  → Qwen redacta el prompt con tu contexto
  → TÚ apruebas en la HUD
  → prometheus_relay.py lanza "claude -p" (headless, sin interfaz)
  → Claude responde
  → resultado vuelve a la HUD
Lo importante: claude -p es el CLI de Claude instalado en tu máquina, no la API web. Funciona con tu suscripción de $20/mes de Claude Pro/Code como crédito separado.

La memoria (Holographic)
Usa algo llamado HRR (Holographic Reduced Representation) — vectores de dimensión 1024 para representar recuerdos como operaciones matemáticas en lugar de búsqueda por texto. Hay dos DBs: memory_store.db para hechos y entidades, state.db para el estado de las sesiones. Actualmente los vectores HRR están todos a NULL — la estructura existe pero no está inicializada.

Los perfiles
Cada modo de Qwen tiene un SOUL.md que define su personalidad/comportamiento:

principal → tu asistente del día a día
codigo → el que gatekeepea Prometheus
nocturno → analiza conversaciones del día
El nocturno (nocturno.py)
Recibe conversaciones completas, las analiza para encontrar patrones. Es la pieza menos definida — el archivo existe pero está enredado con referencias al sistema viejo (freebuff).
